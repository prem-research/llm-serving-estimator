How it works

Pick a model, GPUs and a workload. The estimator works out whether the weights and KV cache fit, then simulates decode and prefill on the hardware's memory bandwidth and compute, the model's MoE and attention structure, tensor-parallel communication and request queueing. Efficiency constants are fitted to public benchmarks; bands show the 10th–90th percentile error measured on held-out data.

Try: Llama-3.3-70B FP8 on 8×H100 · gpt-oss-120b on one H200 · DeepSeek-V4-Flash, 32k prompts, 8×B200

Method

Decode step = max(bytes moved ÷ effective HBM bandwidth, FLOPs ÷ effective peak) + collectives + per-layer overhead, where bytes include only the MoE experts actually touched by the batch and the KV cache read at the current context. Prefill uses causal-attention FLOPs per layer type (full, sliding, MLA, sparse, compressed, linear). Chunked prefill time-shares the GPU with decode; TTFT adds queueing. About 50 efficiency constants are fitted to 15k measurements (InferenceX, WattGPU, SGLang cookbook, community runs); measured model×GPU pairs get a shrunken data correction.
